## Cambridge-pedestrian-accessibility
Cambridge Pedestrian Accessibility Analysis using Python, Machine Learning, and QGIS.
1. Project Overview
This project evaluates pedestrian connectivity, walking distances, and estimated travel times across Cambridge, Massachusetts, using Python, Machine Learning, and QGIS.

2. Objectives
a. Analyze the Cambridge pedestrian network.
b. Identify the 10 longest pedestrian street segments.
c. Evaluate walking distances between selected stations and destinations.
d. Develop a linear regression model to predict walking time.
e. Classify walking distances into four categories.
f. Generate and visualize shortest pedestrian routes.

3. Study Area
Cambridge, Massachusetts, USA.

4. Starting Points
- Porter Square Station
- Inman Square
- Lechmere Station
- Alewife Station

5. Destinations
- Harvard University
- MIT
- Kendall Square
- Central Square
- Cambridge Public Library

6. Tools and Technologies
- Python

7. Methodology
1. Pedestrian network extraction and visualization.
2. Pedestrian street segment analysis.
3. Walking distance and travel time data collection.
4. Linear regression modeling.
5. Distance classification using QGIS.
6. Shortest path analysis and route visualization.
